# Purchase Price Variance (PPV) & Unit Cost Forecasting Model

A practical Excel-based financial model that analyzes **purchase price variance (PPV)** and **gross margin impact** for a consumer electronics product using:
- Real historical cost drivers (2023–2024)
- Actual USD/CNY FX data
- Scenario-based forecasting for FY 2025

The model is structured the way FP&A and supply chain finance teams evaluate cost risk:
**snapshot view → historical evidence → forward-looking impact**.
